# SCARA development CAD

`pickup_placement_tray.scad` and `pickup_placement_tray.stl` define a 240 × 70 × 10 mm
four-station fixture for the simulation pickup pieces. It fits a 256 × 256 mm print
bed and is intended to print flat without supports.

Recommended first prototype: PETG, 0.20 mm layers, four walls, five top/bottom layers,
and 25% gyroid infill. Confirm fit with the actual pieces before treating the pocket
dimensions as final. The original SolidWorks and STEP assets remain unchanged.
